# 视觉帧 A 标定位解析设计

## 目标

将 `parse_vision_frame_computer` 支持的视觉帧更新为：

```text
S,<exec>,<x>,<y>,<yaw>,C,<action...>,B,<block...>,A,<release>,<claw_vertical>,<unused>,E
```

其中 `exec` 表示是否前往第二区，`C` 与 `B` 后分别是不定长的梅花林动作和梅花林格子，`A` 后固定跟随三个整数标定位。

## 数据结构

保留现有 `VisionData_t::exec` 字段，避免影响当前路线逻辑；新增以下三个整数字段：

- `release_flag`：是否松手标定位。
- `claw_vertical_flag`：夹爪上下标定位。
- `unused_flag`：无用标定位，保留协议字段。

坐标继续写入 `x_diff`、`y_diff`，角度继续写入 `angle_x`。

## 解析流程

1. 定位帧头 `S` 和帧尾 `E`。
2. 依次解析 `exec`、`x`、`y`、`yaw`。
3. 验证 `C`，将其后直到 `B` 的非零整数压入动作队列。
4. 验证 `B`，将其后直到 `A` 的非零整数压入方块队列。
5. 验证 `A`，依次解析三个整数标定位。
6. 三个标定位后只允许出现分隔逗号和帧尾 `E`；结构不完整时返回失败。

`C`、`B` 段允许包含零个或多个数字。队列满时沿用现有行为：对应入队操作失败，但不改变整帧解析的成功返回值。

## 兼容性

新格式替换旧格式。缺少 `A` 段或 `A` 后不足三个整数的旧帧、残缺帧均解析失败。现有 `exec`、坐标、角度以及两个队列接口保持不变。

## 验证

新增解析器测试，至少覆盖：

1. 完整帧可解析坐标、角度、两个不定长队列和三个 `A` 标定位。
2. `C`、`B` 为空时仍可解析固定字段。
3. 缺少 `A` 或 `A` 后字段不足时返回失败。
4. 运行现有相关测试，确认结构体扩展未破坏路线代码。
