# KFS 吸取目标以方块中心为基准

## 目标

已上台阶后，底盘为吸取 KFS 生成的移动目标应以当前方块中心坐标为基准，再按当前航向增加固定距离；不再以实时当前位置为基准。

## 范围

- 修改 `ArmComm::pickKFS()` 中已上台阶后的目标坐标计算。
- 将传入的中心坐标参数命名为 `center_x_m`、`center_y_m`，以反映它们既用于取 KFS 偏移基准，也用于取完后的回中心。
- 保持未上台阶前沿世界 X 轴预走的逻辑不变。
- 保持取完 KFS 后的回中心逻辑不变。

## 行为

已上台阶且需要移动时，初始目标为 `(center_x_m, center_y_m)`：

- `45° <= yaw < 135°`：目标 Y 为 `center_y_m + after_step_x_m`。
- `-135° < yaw <= -45°`：目标 Y 为 `center_y_m - after_step_x_m`。
- 其余航向：目标 X 为 `center_x_m + after_step_x_m`。

另一轴始终保持中心坐标值。当前位置继续只用于计算到目标的误差和速度控制。

## 验证

在 `test_arm_comm.cpp` 增加或调整测试，使当前位置和中心坐标不同；验证已上台阶后的移动由中心坐标加固定距离确定，而非由当前位置确定。现有相关测试均须通过。
