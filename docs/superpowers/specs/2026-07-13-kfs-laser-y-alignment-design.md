# KFS 拾取点激光 Y 向精定位设计

## 目标

在 `PICK_KFS_PATH_TO_AREA` 和 `PICK_KFS_PATH_TO_SECOND_AREA` 的视觉粗定位结束后，增加侧向激光精定位。蓝方使用右侧激光，红方使用左侧激光；激光 Y 向误差绝对值小于 30 mm 并稳定后，进入原有机械臂等待状态。

## 参数

在 `conbat_task.cpp` 中增加单位为 mm 的可赋值目标表：

```cpp
float CONBAT_PICK_KFS_LASER_TARGET_MM[2][2] = {
    {0.0f, 0.0f}, // 蓝方：第一个、第二个位置
    {0.0f, 0.0f}, // 红方：第一个、第二个位置
};
```

目标值为 `0.0f` 或所选激光数据无效时，底盘停车等待，防止使用未标定数据运动。

## 状态与控制

两个现有跑点状态各自保留视觉粗定位，并共用一个激光精定位子阶段标志：

1. 视觉 x/y 误差达到现有阈值并满足现有稳定周期后，清零速度和稳定计数，锁定进入激光子阶段。
2. 激光子阶段只输出世界系 Y 向速度，世界系 X 向速度为零。
3. 蓝方右激光的 Y 误差为 `目标距离 - 测量距离`。
4. 红方左激光的 Y 误差为 `测量距离 - 目标距离`。
5. 激光误差绝对值小于 30 mm 并满足对应跑点原有稳定周期后，进入原有机械臂等待状态。

激光子阶段一旦进入便不再退回视觉粗定位，避免视觉抖动导致控制源反复切换。进入第一个或第二个跑点前均重置子阶段标志。

## 改动范围

仅修改：

- `R2_Lift_auto/MDK-ARM/TASK/conbat_task.cpp`
- `R2_Lift_auto/MDK-ARM/TASK/conbat_task.h`

不修改现有 FTM 阵营激光映射，也不改动其他路径和机械臂流程。

## 验证

- 检查蓝方选择 `laser_right`，红方选择 `laser_left`。
- 检查两个 KFS 目标分别使用目标表的索引 0 和 1。
- 检查无效激光和零目标值均只产生停车输出。
- 检查左右激光误差符号能产生正确的世界系 Y 修正方向。
- 执行项目可用的编译或语法检查，确认新增代码无编译错误。
