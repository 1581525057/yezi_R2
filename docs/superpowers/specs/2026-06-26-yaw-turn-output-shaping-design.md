# Yaw 转弯输出整形设计

## 背景

当前路线层转弯已经直接给最终 `yaw_target`，底盘层通过 `pid_yaw.PID_Calculate_Angle(vision.angle_x, yaw_target)` 输出 `target_vz`。实车现象是转弯末段变慢，同时起停不够顺，表现为接近目标角时拖尾、刹停阶段可能顿挫或抖动。

## 目标

- 保留路线层直接给最终目标角的逻辑，不恢复慢速目标角斜坡。
- 在底盘层改善 yaw 转弯末段拖尾。
- 接近目标角时让输出自然收小，减少冲过目标角和停下抖动。
- 改动尽量小，只影响 yaw 角速度输出整形。

## 方案

在 `chassis_task.cpp` 中新增一个底盘层 yaw 输出整形函数，输入为 PID 原始输出、当前 yaw 和目标 yaw，输出为整形后的 `target_vz`。

整形规则：

- 先计算最短角度误差，范围归一到 `[-180, 180]`。
- 当误差大于外层阈值时，保持一个最小角速度，避免小误差时 PID 输出太小导致末段拖尾。
- 当误差处于内外阈值之间时，最小角速度按误差线性下降，保证靠近目标角时逐渐收小。
- 当误差小于内层阈值时，不再强行保底，让转弯完成判定和 PID 小输出自然接管。
- 输出方向保持 PID 原始输出方向；如果 PID 原始输出接近 0，则根据角度误差方向补方向。

建议初始参数：

- 内层阈值：`1.5f` 度，匹配路线层转弯到位阈值。
- 外层阈值：`6.0f` 度，覆盖末段拖尾区间。
- 最小角速度：`0.45f` rad/s，作为保守起点，后续可实车微调。

## PID 参数策略

本次不大幅调 PID。先保留现有 `pid_yaw.Init(2.5, 0.8, 1.0, 0.10, 0.1, 0, 0, 0x00)`，只通过输出整形改善末段。如果实车仍有明显停下抖动，再单独考虑降低 `Ki` 或把 `Ki` 置 0。

## 验证

- 用 `rg` 确认慢转逻辑没有被重新引入。
- 用 `arm-none-eabi-g++ -fsyntax-only` 静态检查 `chassis_task.cpp`。
- 实车观察 90 度和 180 度转弯：末段不拖尾，靠近目标角不过冲或少过冲，停下无明显抖动。
