# AS5047P磁编码器

## 模块概述

AS5047P 是一颗 **14位非接触式磁编码器**，通过 SPI 读取角度和诊断状态。工程中使用 SPI1 接口，每帧读取 ANGLECOM（动态误差补偿后角度），精度 0.022°/LSB。

## 硬件连接

| 信号 | 引脚 |
|------|------|
| 片选（CS） | GPIOE_15 |
| SPI 接口 | SPI1 |

## 关键寄存器

| 寄存器 | 地址 | 说明 |
|--------|------|------|
| ANGLECOM | 0x3FFF | 补偿后角度（14位，读后自动更新） |
| ERRFL | 0x0001 | 错误标志（读后清零） |
| DIAAGC | 0x3FFC | 诊断+AGC增益 |

## SPI 帧格式（16位）

```
发送命令帧：
    Bit15 = R/W（1=读，0=写）
    Bit14 = 偶校验位
    Bit13~0 = 寄存器地址

接收数据帧（下一拍读出）：
    Bit15 = EF（错误标志，1=上帧有误）
    Bit14 = 偶校验位
    Bit13~0 = 寄存器数据
```

AS5047P 使用**流水线读取**：发送命令后，下一次 SPI 事务才接收到本次命令的结果。

## 接口

```cpp
void init(SPI_HandleTypeDef *hspi);  // 绑定SPI，清零data缓存

void updata(void);
// 固定顺序：
// 1. 读ANGLECOM → angle_raw, angle(度), EF标志
// 2. 若EF=1 → 读ERRFL → 缓存错误信息
// 3. 读DIAAGC → 更新诊断缓存（磁场强度、CORDIC状态等）

uint16_t readErrorRegister(void);    // 主动读ERRFL（读后清零）
uint16_t readDiagAgcRegister(void);  // 主动读DIAAGC
```

## 数据结构

```cpp
AS5047_Data_t {
    float    angle;            // 角度（度，0~360）
    uint16_t angle_raw;        // 原始14位值（0~16383）
    uint8_t  frame_error_flag; // EF：上帧命令错误标志

    uint16_t errfl_raw;        // ERRFL原始值
    uint8_t  errfl_parerr;     // 奇偶校验错误
    uint8_t  errfl_invcomm;    // 无效命令错误
    uint8_t  errfl_frerr;      // SPI帧错误

    uint16_t diaagc_raw;       // DIAAGC原始值
    uint8_t  diaagc_magl;      // 磁场过弱
    uint8_t  diaagc_magh;      // 磁场过强
    uint8_t  diaagc_cof;       // CORDIC溢出（角度不可信）
    uint8_t  diaagc_lf;        // 内部补偿完成
    uint8_t  diaagc_agc;       // AGC增益值（0~255）
}
```

## 在工程中的应用

- 每 1ms 在 `usart_task` 中调用 `as5047.updata()`
- 角度数据可用于机构位置反馈（当前通过调试帧发送，未接入控制闭环）
