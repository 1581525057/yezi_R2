# yezi_R2 项目总览

## 项目基本信息

| 项目 | 内容 |
|------|------|
| 项目名称 | yezi_R2 |
| 主控芯片 | STM32H723（ARM Cortex-M7，480MHz） |
| RTOS | FreeRTOS（heap_4 内存管理） |
| 开发工具 | MDK-ARM（Keil），STM32CubeMX |
| 工程文件 | `My_Princess_cpp.ioc` |

## 核心功能

yezi_R2 是一台竞赛机器人，主要功能包括：

- **全向轮底盘控制**：四轮全向底盘，支持任意方向移动
- **升降机构控制**：双侧云深J60电机 + 2006辅助轮，高度轨迹规划
- **半自动上台阶**：激光测距 + 状态机，全自动完成爬坡流程
- **多种电机驱动**：DJI（3508/2006）、云深J60、VESC、达妙DM_8009
- **传感器采集**：DT35模拟传感器（SPI+ADS8688）、AS5047P磁编码器、激光测距
