## 模块概述

DT35 是一款激光位移传感器，输出 **0~10V 模拟电压信号**，经由 ADS8688 16位 ADC 转换后通过 SPI 接入 STM32H723。模块文件 `DT35.h/.cpp` 封装了完整的初始化、采样、换算流程。

## 硬件连接

```
DT35传感器 → 模拟电压(0~10V) → ADS8688 ADC → SPI3 → STM32H723
```

| 信号 | 引脚 |
|------|------|
| ADS8688 片选（CS） | GPIOE_14 |
| ADS8688 复位（RST） | GPIOB_8 |
| SPI 接口 | SPI3 |

## 量程配置

```
ADS8688 CH0 量程：0 ~ 10.24V（单极性）
DT35 输出：0V → 30mm，10V → 30000mm
换算公式：
  voltage_V    = adc_raw × (10.24 / 65535)
  distance_mm  = DT35_DIST_AT_0V_MM +
                 (voltage_V / DT35_VOLTAGE_MAX_V) × (DT35_DIST_AT_10V_MM - DT35_DIST_AT_0V_MM)
```

## 接口

```cpp
void init(SPI_HandleTypeDef *hspi);
// 硬复位→软复位→CH0/CH1量程配置→手动CH0采样模式

void update(void);
// 执行双通道采样：CH0 → ch0, CH1 → ch1
// 换算 voltage_V, distance_mm, 置 valid=1

DT35_Data_t ch0;   // CH0（主通道）采样结果
DT35_Data_t ch1;   // CH1（副通道）采样结果
DT35_Data_t &data = ch0;  // 兼容旧代码的引用
```

## 数据结构

```cpp
DT35_Data_t {
    float    distance_mm;  // 距离（mm）
    float    voltage_V;    // 采样电压（V）
    uint16_t adc_raw;      // 原始16位ADC值
    uint8_t  valid;        // 数据有效标志（0/1）
}
```

## SPI 通信流程（ADS8688）

```
1. CS拉低
2. 发送16位命令字（如 MAN_CH0=0xC000）
3. 接收16位数据（流水线：本次发送命令，下次接收上次命令结果）
4. CS拉高
```

详细寄存器定义参见：`说明文档/DT35_ADS8688_使用文档.md`

## 在 usart_task 中的使用

```
每 1ms：dt35.update()
调试帧中发送：ch0.voltage_V, ch1.voltage_V, ch0.distance_mm, ch1.distance_mm
```
