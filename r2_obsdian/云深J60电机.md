## 模块概述

`Yun_J60_Class`（`yun_j60.h/.cpp`）封装了云深处 J60 关节电机的 FDCAN 通信驱动。J60 电机工作在**位置-速度-力矩混合控制**（MIT 模式）下，通过 FDCAN 以自定义浮点打包协议通信。

## 电机分配

| ID | 位置 | 方向 |
|----|------|------|
| 0x02 | 左侧升降 | 角度取负（安装反向） |
| 0x03 | 右侧升降 | 正向 |

## 协议说明（MIT模式）

发送帧（8字节）内容按位打包：
```
[p_des (16bit)] [v_des (16bit)] [kp (12bit)] [kd (12bit)] [t_ff (12bit)]
```
浮点数通过 `float_to_uint` 压缩为定点整数后打包。

接收帧（8字节）内容：
```
[id (8bit)] [position (16bit)] [velocity (12bit)] [torque (12bit)]
```
通过 `uint_to_float` 解包还原为实际量。

## 控制参数范围

| 参数 | 范围 |
|------|------|
| 位置 p_des | -12.5 ~ +12.5 rad |
| 速度 v_des | -65.0 ~ +65.0 rad/s |
| 刚度 kp | 0 ~ 500 |
| 阻尼 kd | 0 ~ 5 |
| 前馈力矩 t_ff | -18 ~ +18 N·m |

## 核心接口

```cpp
static void EnableMotor(uint8_t id);
// 发送使能帧，让电机进入控制模式

static void SendControl(uint8_t id,
    float p_des, float v_des, float kp, float kd, float t_ff);
// 发送位置-速度-力矩控制帧

static void RxHandler(FDCAN_RxFrame_TypeDef *rxframe, uint8_t Data[8]);
// 解析接收帧，更新 motor[id].position/velocity/torque/temperature
```

## 数据结构

```cpp
Dog_j60_motor_t motor[8] {
    float position;     // 当前位置（rad）
    float velocity;     // 当前速度（rad/s）
    float torque;       // 当前力矩（N·m）
    float temperature;  // 电机温度
}
```

## 在升降任务中的应用

```
J60角度 → 高度(mm) = angle × HEIGHT_DIAMETER / 2.0
pid_lift_left/right 输出 → 作为 kp、t_ff 传入 SendControl
v_des = 0（纯位置控制时）
```
