## 模块概述

`LaserDistance`（`laser_distance.h/.cpp`）通过 USART + DMA 接收激光测距仪的串口数据帧，解析距离值（mm/m），用于半自动上台阶的距离判断。

## 硬件配置

- 通信接口：USART（具体通道见工程配置）
- 接收方式：DMA 双缓冲（`rx_buf[2][32]`），空闲中断触发解析

## 数据结构

```cpp
struct Laser_data {
    float    distance_m;    // 距离（米）
    uint32_t distance_mm;   // 距离（毫米）
    uint16_t error_code;    // 错误码
    uint8_t  valid;         // 数据有效标志（1=有效）
    uint8_t  error;         // 错误标志（1=有误）
}

LaserDistance {
    Laser_data data;
    uint8_t rx_buf[2][32];  // DMA双缓冲
}
```

## 接口

```cpp
LaserDistance();
void clearData(void);                               // 清零数据
void laser_parse_dma_data(uint8_t *data, uint16_t len);  // 解析DMA接收帧
```

## 在半自动上台阶中的用法

```cpp
// lift_auto.cpp 中每帧读取
float dist = (float)laser.data.distance_mm;

// 各状态的距离判断：
// APPROACH_Y:     dist <= 110mm → 切换到 WAIT_NEW_HEIGHT
// WAIT_NEW_HEIGHT: dist ~= 1120mm ±30mm 持续10帧 → 切换到 CLIMB_FORWARD
// CLIMB_FORWARD:  dist <= 490mm → 切换到 FINISHED
```

## 数据流

```
激光测距仪 → USART（DMA接收）→ laser_parse_dma_data() → laser.data.distance_mm
                                                              ↓
                                                    lift_auto 状态机判断
```
