## 模块概述

`Remote`（`bsp_remove.h/.cpp`）解析大疆 SBUS 协议遥控器，通过 USART + DMA 接收，提供底盘速度指令和拨杆状态。

## 硬件配置

- 接收协议：SBUS（大疆 DB16 / DT7 遥控器）
- 接收缓冲：`SBUS_MultiRx_Buff[2][18]`（双缓冲，18字节/帧）
- 通道中值偏移：1024（大疆标准）

## 数据结构

```cpp
RC_Info_t {
    int16_t ch[5];   // 5路遥控通道（已减去1024偏移，范围约±660）
    uint8_t s[2];    // 2个拨杆状态（1=上, 2=中, 3=下）
}

Chassis_Cmd_t {
    float Vx;   // X向目标速度（m/s）
    float Vy;   // Y向目标速度（m/s）
    float Vz;   // 角速度（rad/s）
    float Vl;   // 升降目标速度（m/s）
}
```

## 核心接口

```cpp
void parseSBUS(const uint8_t *sbus_buf);    // 解析SBUS帧，更新 rc_
void updateChassosCommand();                 // ch[] → Vx/Vy/Vz/Vl（含比例换算）
void monitor();                              // 在线检测（离线则 reset()）

const RC_Info_t &getRC() const;             // 获取通道原始数据
const Chassis_Cmd_t &getChassosCmd() const; // 获取底盘速度指令
bool isLost() const;                         // 遥控器是否离线
```

## 通道映射（大疆 DT7 / DB16）

| 通道 | 含义 | 最大值 |
|------|------|--------|
| ch[0] | 右摇杆左右（底盘Vx） | 660 |
| ch[1] | 右摇杆上下（底盘Vy） | 660 |
| ch[2] | 左摇杆上下（底盘Vl/升降） | 660 |
| ch[3] | 左摇杆左右（底盘Vz） | 660 |
| ch[4] | 拨轮（辅助） | 660 |
| s[0] | 左拨杆（3档：1上/2中/3下） | — |
| s[1] | 右拨杆（3档：1上/2中/3下） | — |

## 在工程中的应用

```
chassis_task 每 1ms：
  remove_dji.monitor()            → 离线检测
  remove_dji.updateChassosCommand() → 刷新 Vx/Vy/Vz
  remove_dji.getChassosCmd().Vx/Vy/Vz → 传入底盘控制

lift_auto 读取拨杆状态：
  remove_dji.getRC().s[0] == 1 AND s[1] == 1 → 触发自动上台阶
```

## 遥控器离线保护

```
monitor() 每帧检查：
  若 SBUS 帧超时（online_cnt_ 减为0） → rc_lost_ = true
  isLost() 返回 true → chassis_task 停止一切控制输出
```
