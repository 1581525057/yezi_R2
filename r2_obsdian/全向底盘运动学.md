## 模块概述

`OmniChassis`（`omni_chassis.cpp`）封装了四轮全向底盘的完整运动学与动力学解算，通过 CMSIS-DSP 矩阵运算库实现。

## 机械参数

| 参数 | 值 |
|------|-----|
| 轮子半径 | 76.26mm（`wheel_r = 0.15252/2`） |
| 轮子周长 | `wheel_r × 2π` |
| 最大转速 | 450 RPM |
| 底盘矩阵系数 a | 0.7071（sin45°） |
| 底盘矩阵系数 b | 0.3684（轮距参数） |

## 核心接口

```cpp
void setRemote(float Vx, float Vy, float Vz);    // 设置目标速度（m/s，rad/s）
void forwardKinematics();                          // 正运动学：轮速 → 底盘速度
void inverseKinematics();                          // 逆运动学：底盘速度 → 各轮RPM
void dynamicsInverse(float Fx, float Fy, float T); // 动力学逆解：合力 → 各轮电流前馈
```

## 运动学解算原理

### 正运动学（forwardKinematics）
```
各轮 RPM → 底盘 Vx、Vy、Vz
用于反推底盘当前实际速度，参与速度闭环
```

### 逆运动学（inverseKinematics）
```
底盘目标 Vx、Vy、Vz → 各轮目标 RPM
四轮全向轮布局（X形/45°安装），运动学矩阵：
    wheel0 =  a×Vx + a×Vy + b×Vz
    wheel1 = -a×Vx + a×Vy - b×Vz
    wheel2 = -a×Vx - a×Vy + b×Vz
    wheel3 =  a×Vx - a×Vy - b×Vz
（具体符号由安装方向决定）
```

### 动力学逆解（dynamicsInverse）
```
底盘合力 Fx、Fy → 各轮需要输出的电流前馈
与 PID 输出叠加后送入电机，提升动态响应
```

## 数据结构

```cpp
Speed_t {
    float Vx, Vy, Vz;      // 底盘速度（m/s, m/s, rad/s）
    float rpm[4];           // 各轮转速（RPM）
}

OmniChassis {
    Speed_t target;         // 目标速度
    Speed_t now;            // 当前速度（由正运动学得到）
    float Current_rpm[4];   // 动力学前馈电流
    uint8_t flag;           // 0=普通模式, 1=无头模式（预留）
}
```

## 与底盘任务的协作

```
chassis_task 每 1ms：
  1. 读取电机RPM → omni_chassis.now.rpm[]
  2. forwardKinematics() → 得到 now.Vx/Vy
  3. setRemote(Vx, Vy, Vz) → 设置 target
  4. 速度PID → Fx, Fy
  5. dynamicsInverse(Fx, Fy) → Current_rpm[]（前馈）
  6. inverseKinematics() → target.rpm[]
  7. 转速PID输出 + Current_rpm → 最终电流
```
